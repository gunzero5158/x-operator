# x-operator

X（推特）运营半自动化工具：AI 负责找目标、匹配素材、写文案，人负责最终审核。
不绑定任何业务，可用于任何产品、语言、市场。

## 功能

- **多账号**：官方 API（主号）+ 小号 Cookie / 密码登录，自动轮流回复，各账号独立限速与活跃时段
- **找推文**：监控指定推主、关键词搜索、小号推荐流（For You），按语义条件和观看量筛选
- **写回复**：匹配素材库、AI 按要求创作，或只抓取手动处理；支持配图 / 视频
- **定时发帖**：固定素材、素材池轮流、AI 按主题创作，可 AI 改写避免重复
- **人工审核**：所有内容先进审核队列，批准后才发；发送后自动回查是否真的发出
- **合规护栏**：黑名单、作者冷却、去重、日上限、推文长度检查、官方 API 读额度熔断

## 快速开始

需要 [uv](https://docs.astral.sh/uv/)。Windows 双击 `start.bat`，或：

```bash
uv sync
uv run python -m x_operator.main
```

浏览器打开 http://localhost:8080，按仪表盘的「就绪检查」依次完成：
添加账号 → 加几条素材 → 添加监控推主或搜索规则 → 点「运行一次」。

LLM 在「设置 → LLM」填任意 OpenAI 兼容端点即可，不填也能用，只是打分粗一些。

## 注意

- 页面**没有登录保护**，默认只监听本机 127.0.0.1，不要改成 0.0.0.0 暴露到公网
- 所有数据（账号、密钥、素材、记录）都在 `data/` 目录，不会上传；备份 = 复制该目录
- 只有官方 API 通道花钱，小号通道 X 不计费
- 请只在你有权操作的账号上使用，遵守 X 服务条款；自动化回复有封号风险，务必保守限速
