# x-operator

X（推特）运营半自动化工具，跑在你自己的电脑上。
AI 负责找目标推文、挑素材、写文案；你负责最后一道审核，批准了才发。
不绑定任何业务，可用于任何产品、语言、市场。

## 亮点

- **找得到人**：监控指定推主、关键词搜索、小号推荐流（For You）三种来源。每条推文先按语义条件、语言、观看量筛一遍，被过滤的会写明原因，不会莫名其妙漏掉。
- **回复有底稿**：素材库里的回复素材按语言和场景自动匹配；也可以让 AI 按你的创作要求现写，或者只抓取、手动处理。创作要求可以存成模板反复用。
- **主贴自己发**：定时发帖支持固定素材、素材池轮流、AI 按主题创作三种模式。周期计划可开 AI 改写变体，避免 X 判重复拒发。
- **配图 / 视频**：回复和主贴都能带附件，规则和 X 一致。定时发帖可挂一个附件素材池，每次随机挑一个。同一张图在不同地方上传只存一份。
- **多账号分摊**：主号走官方 API，小号走 Cookie 或密码登录。回复和抓取在小号之间轮流挑最闲的，各账号独立设日上限、发送间隔、活跃时段和时区。
- **发前发后都有保护**：黑名单、同作者冷却、去重、推文长度检查、官方 API 读额度熔断。发送后自动回查推文是否真的存在，发送接口说成功不算数。
- **全部本地**：账号凭据、素材、记录都在 `data/` 目录，不上传。换电脑带走这个目录即可。

## 三分钟上手

需要 [uv](https://docs.astral.sh/uv/)。Windows 双击 `start.bat`，Linux / macOS 运行 `start.sh`，或手动：

```bash
uv sync
uv run python -m x_operator.main
```

浏览器打开 http://localhost:8080，跟着仪表盘的「就绪检查」走：

1. **设置 → 账号**：添加一个账号，点「测试连接」。主号用官方 API 的四个密钥；小号从浏览器复制 `auth_token` 和 `ct0` 两个 Cookie，或填用户名、密码和两步验证密钥让程序自己登录。弹窗里有图文步骤。
2. **素材库**：加几条「回复」素材。语言会按正文自动判断，不准可以手选。
3. **监控推主** 或 **搜索规则**：加一个来源，选回复方式，点「运行一次」。
4. **任务队列**：看 AI 生成的草稿，改文案、换素材、批准或跳过。批准后由分发器在账号的活跃时段内发出。
5. 跑顺了再到 **设置 → 自动运行** 打开总开关，让搜索和监控按节奏自己跑。

LLM 在「设置 → LLM」填任意 OpenAI 兼容端点即可。不填也能用，只是筛选和匹配用规则兜底，没有 AI 写作。

## 注意

- 页面**没有登录保护**，默认只监听本机 127.0.0.1，不要改成 0.0.0.0 暴露到公网。
- 只有官方 API 通道按量收费，小号通道 X 不计费。抓取默认只用小号、多个小号自动分摊限额；官方 API 参与抓取要在「设置 → 抓取」手动打开。
- 请只在你有权操作的账号上使用，遵守 X 服务条款。自动化回复有封号风险，务必保守限速。
